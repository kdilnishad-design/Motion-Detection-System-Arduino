# Motion Detection System using Arduino

## Components
- Arduino Uno
- PIR Sensor
- 16x2 I2C LCD
- LED
- 220Ω Resistor

## Working
The PIR sensor detects motion.
When motion is detected:
- LED turns ON
- LCD displays "Motion Detected"

When there is no motion:
- LED turns OFF
- LCD displays "No Motion"
